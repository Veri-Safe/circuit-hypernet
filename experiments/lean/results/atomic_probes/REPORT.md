## 旧18组尚需完成的部分

旧18组全部沿用修正前的 And 标签。四个未改标签的组合族及原子题只保留为口径不变的历史聚合；And-Or 和组合总计不冒充已重算。完整结果需服务器读取已冻结 fits.pt 与四路 evaluation.pt，仅 CPU 做线性读出和重评分，原选参保持不变。

本地旧冻结 λ=.001 对照已按逐题分数重算；不能用历史28项聚合一致冒充整个18组 sweep 的逐题重算。

新 v2 没有做 clean 原子前向，因此新探针 clean 原子结果缺失，不从原题或旧探针填充。

原题忽略 ID、原题 one-hot top1 和 clean 四候选只保留原档，不用作本轮完整原子能力识别结论。

探针训练仍用原子任务 one-hot（ID=直接引用），而本轮 ID 评测还要求识别题面干扰；这是已存在的训练监督覆盖限制，不能通过评分时删除相关 ID 来绕开。
